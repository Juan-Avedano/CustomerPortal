# 🌐 Customer Portal - Plataforma de Autogestión para Telecomunicaciones

Este proyecto constituye mi **Trabajo Final de Tésis** para la carrera de Técnico en Desarrollo de Software en el Instituto Superior Santo Domingo (ISSD), Córdoba, Argentina. El proyecto fue defendido con éxito, obteniendo una calificación de **9/10**.

## 📝 Problemática y Solución
"Customer Portal" es una solución integral diseñada para resolver el desgaste en la comunicación entre cliente y empresa en el sector de las telecomunicaciones. La plataforma dota de autonomía total al usuario, permitiendo gestiones que antes requerían asistencia telefónica, optimizando así la eficiencia operativa de la compañía.

## ✨ Características Destacadas
* **Autonomía Total:** Gestión de servicios contratados, adquisición de packs de datos y abono de facturas de forma 100% online.
* **Seguridad Avanzada (MFA):** Implementación de autenticación multifactor (MFA) utilizando **Google Authenticator (TOTP)** para garantizar la integridad de los datos sensibles de los usuarios.
* **Trazabilidad Geográfica:** Integración con la **API de Google Maps** para el seguimiento y visualización en tiempo real de visitas técnicas y cobertura de servicio.
* **Soporte Inteligente:** Incorporación de un **Chatbot** para la resolución de consultas frecuentes con derivación lógica a agentes humanos para casos complejos.

## 🛠️ Stack Tecnológico
* **Backend:** Python utilizando el framework **Flask**.
* **Base de Datos:** **PostgreSQL** para la gestión robusta de datos relacionales.
* **Frontend:** **JavaScript**, Jinja2, HTML5 y CSS3 para una interfaz dinámica y centrada en la experiencia de usuario (UX).
* **Seguridad:** Flask-Login y cifrado de datos para el manejo de sesiones.
